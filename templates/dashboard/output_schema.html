Schema Standardization

Output Gate · All responses normalized to OpenAI-compatible JSON

Regardless of which AI provider handles a request (DeepSeek, Gemini, Anthropic, or a custom model), every response is translated into the standard OpenAI Chat Completion format before delivery. Your clients never need to change their integration code if you switch providers.

1 · Provider Raw Response

Each AI provider returns a slightly different JSON shape. Gemini wraps in candidates[], Anthropic uses content[], DeepSeek mirrors OpenAI closely but with subtle differences.

// Gemini raw
{ "candidates": [{
  "content": { "parts": [{ "text": "..." }] }
}] }

3 · Standardized Output

Every response exits the gateway looking like an OpenAI chat.completion object. Drop-in compatible with any OpenAI SDK.

// Standard (OpenAI-compatible)
{ "choices": [{
  "message": { "role": "assistant",
    "content": "..." }
}] }
