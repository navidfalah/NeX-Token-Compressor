Gateway Telemetry Headers

Output Gate · Metadata injected into every HTTP response

Every response leaving the gateway carries custom X-Gateway-* headers. These are machine-readable and allow client applications to observe compression savings, routing decisions, and latency without parsing the response body.

Reading Headers From Your App
Python (httpx)
resp = httpx.post(
    "http://gateway/v1/chat/completions",
    headers={"Authorization": "Bearer fk-..."},
    json={...}
)
saved  = resp.headers["X-Cost-Saved-USD"]
model  = resp.headers["X-Model-Used"]
tokens = resp.headers["X-Tokens-Original"]
JavaScript (fetch)
const resp = await fetch(
  "http://gateway/v1/chat/completions",
  { method:"POST", headers:{...}, body: ... }
);
const saved = resp.headers.get("X-Cost-Saved-USD");
const model = resp.headers.get("X-Model-Used");
