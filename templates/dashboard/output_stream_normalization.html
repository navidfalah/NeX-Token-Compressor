Stream Chunk Normalization

Output Gate · Server-Sent Events unified across all providers

When streaming is enabled ("stream": true), AI providers send data in completely different chunk formats. The gateway intercepts every fragment, repackages it into a standardized SSE format identical to OpenAI's, and re-streams it — so your client never knows which model was actually used.

  -H "Authorization: Bearer fk-your-key" \

  -d '{"messages":[...],"stream":true}'
